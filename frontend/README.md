# Frontend ? RicePest Spotter

## Purpose
Offer a responsive interface for agricultural
pest image screening.

## Planned user workflow
1. Upload or select a photograph.
2. Preview and validate the image.
3. Send the image to the actual inference API.
4. Display detected objects with bounding boxes.
5. Show pest class labels and confidence.
6. Show estimated total and per-class object counts.
7. Export results if supported.

## Requirements
Frontend must display real backend outputs,
not simulated detection boxes.

Provide:
- Empty, loading, success and error states
- Mobile-friendly layout
- Responsible usage disclaimer
- Clear confidence threshold information
- Accessible file upload workflow
