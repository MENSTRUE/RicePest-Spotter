# Visual Evidence

## plots/
Real learning curves, dataset distributions,
precision-recall curves and evaluation charts.

## examples/
Real source image examples and model detections.
Preserve annotation and prediction distinctions.

## screenshots/
Screenshots of an actually running application.
Do not create fake application evidence.

## diagrams/
Research and system architecture diagrams.

Evidence rules:
- Preserve source and evaluation context
- Identify validation vs test
- Do not create fake predictions
- Respect image licensing and attribution
- Avoid committing complete raw datasets
